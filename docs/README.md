# Trip Docs

Start here: **[TRIP_CONTEXT.md](./TRIP_CONTEXT.md)** — the master reference. Travelers, every
confirmed booking, insurance, dietary rules, and everything still undecided.

The rest is source material for refining the plan — some of it has since been applied (see
TRIP_CONTEXT.md §7), the rest is still pending (§8):

| File | What it is |
|---|---|
| [Cyprus_Trip_Overview.md](./Cyprus_Trip_Overview.md) | The day-by-day itinerary booklet, in prose form — updated as changes are applied. The site's `src/data/days.ts` is the live/interactive version of this. |
| [Cyprus_Trip_Critique.md](./Cyprus_Trip_Critique.md) | A logistics/safety review pass (wildfire risk, boat trip timing, pacing) — a point-in-time snapshot, kept as-is even as items get applied elsewhere. |
| [Cyprus_TourGuide_Review.md](./Cyprus_TourGuide_Review.md) | A "what's missing, what to skip" review against real family-travel sources — same, kept as a snapshot. |

Booking confirmations, insurance policy PDFs, and the flight manifest live in the Google Drive
folder and `~/Downloads/cyprus/`, not in this repo.
